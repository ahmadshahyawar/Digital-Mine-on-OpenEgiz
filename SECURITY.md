# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed credential. Use GitHub's private security advisory form for this repository instead.

Include the affected component, reproduction steps, potential impact and the smallest safe evidence needed to understand the report. Do not include real mine data, credentials or unrelated personal information.

## Supported version

Security fixes target the latest commit on `main`. Ademix is a demonstration and research project; it is not a safety-critical control system and should not be deployed as one.
