# Ademix Data and Asset Layer

This directory is the inspection point for the mine inputs used by the Ademix digital twin. It separates sourced reference parameters from synthetic live telemetry and bundled visual assets.

| File | Purpose |
| --- | --- |
| `fleet_specs.csv` | Human-readable fleet and facility parameters used by the reduced demonstration mine |
| `telemetry_dictionary.csv` | Meaning, unit, origin, and update behavior of every live field shown by the twin |
| `model_manifest.csv` | Inventory, provenance, license, size, and checksum of bundled 3D models |
| `openmines/north_pit_mine.json` | Unmodified MIT-licensed calibration reference from OpenMines |

## Data classification

- **Sourced reference:** values taken or derived from the included OpenMines North Pit configuration.
- **Team assumption:** a documented simplification chosen for a clear, reproducible demonstration.
- **Synthetic telemetry:** deterministic runtime state generated by the simulator. It is not physical mine sensor data.
- **Bundled asset:** a locally stored, license-checked 3D model used by the interface.

`fleet_specs.csv` and `telemetry_dictionary.csv` are explanatory inventories. The executable simulation remains the source of runtime state; these files must be updated whenever its public parameters or telemetry schema changes.
