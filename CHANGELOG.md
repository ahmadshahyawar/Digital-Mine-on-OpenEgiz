# Changelog

All notable public releases of Ademix are documented here.

## 1.0.0 — 2026-10-28

- Released the Docker Compose deployment for the complete OpenEgiz and Ademix stack.
- Connected 11 Eclipse Ditto twins through MQTT to the live API and 3D interface.
- Added deterministic loading, haulage, crusher, queue and mass-balance simulation.
- Added truck breakdown, road restriction and crusher slowdown scenarios.
- Added Smart Dispatch, fleet-sizing evidence and sensitivity analysis.
- Added clean Ubuntu 24.04 verification, repeated smoke checks and restart recovery.
- Documented synthetic-data limitations and third-party data and asset provenance.
